# SnakeDefender

세로 스크롤형 디펜스. 뱀 형태 적이 경로를 따라 오고, 플레이어(타워)가 위로 쏴서 몸통·머리 HP를 깎는 구조.

Unity 6 (`6000.3.x` 기준).

---

## 과제 요구사항

| 구분 | 내용 | 완료 |
|:--|:--|:--:|
| 필수 | 적 생성 및 이동, 영웅 공격, 적 체력 감소, 적 사망 처리 | ✅ |
| 필수 | 몸통 파괴 시 머리를 몸 쪽으로 당기는 처리 | ✅ |
| 필수 | 승리(적 처치) 및 실패(도착 지점 도달) 판정 | ✅ |
| 선택 | 구간별 적 광폭화(머리 표정·속도 증가 등) | ✅ |
| 선택 | Splines 없이 적 이동 구현 | ✅ |

---

## 내부 동작 요약

- **적 이동**: 웨이포인트를 잇는 경로(`PathRoute`) 위에서 거리만큼 진행하는 방식.
- **몸통 파괴**: 몸통이 깨지면 진행 거리를 한 칸 줄여서 머리가 뒤로(몸 쪽으로) 당겨짐.
- **공격**: 타워가 쿨타임마다 위쪽에 적이 있으면 총알 발사 → 몸통 HP 감소 → 0이면 파괴.
- **승패**: 목표 처치 수를 채우면 승리, 머리가 플레이어에 닿거나 경로 끝까지 오면 실패.
- **광폭화**: 몸통을 일정 수 이상 파괴되면 속도 상승, 머리 표정은 스프라이트 색 교체로 구현.
- **UI**: 몸통 위 HP·데미지 숫자는 월드 기준으로 화면에 붙임.

---

## 추가 기능

- **스펙업 UI**: 몸통을 일정 개수 파괴할 때마다 스펙업 창이 뜨고, 공격력·공격 속도·총알 수(발사량) 중 하나를 고름.
- **좌우 이동**: 플레이어를 누른 채 좌우로 끌면 화면 안에서만 옆으로 움직임.

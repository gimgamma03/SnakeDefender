# SnakeDefender

세로 스크롤형 타워 디펜스. 분절형 뱀 적이 웨이포인트 경로를 따라 내려오고, 화면 하단의 타워가 위쪽으로 사격해 머리·몸통 HP 를 깎는 구조.

외부 패키지(Unity Splines 등) 의존 없이 **순수 Unity API 만으로 디펜스 한 사이클을 구현한 개인 작업물**입니다.

**플레이 영상** → https://youtu.be/CHhoJfeY6Qs

## 주요 기능

### 적 시스템
- **분절형 뱀 적** — 머리 + 몸통 N칸 구조, 몸통 파괴 시 자연스러운 압축 연출
- **웨이포인트 기반 경로 이동** — Splines 없이 거리 기반 샘플링 (`PathRoute`)
- **다단계 페이즈 + 분노 상태** — 파괴 누적 수에 따라 머리 스프라이트 교체 / 속도 상승 / 색 변경
- **세그먼트별 HP·티어** — 몸통 N칸 단위로 HP 가산해 난이도 곡선 형성

### 플레이어 / 전투
- **자동 사격 타워** — 위쪽 Raycast 로 사격 가능 대상이 있을 때만 발사
- **다탄 발사 / 강화 단계** — 강화 단계에 따라 좌·우 대칭 각도로 추가 발사
- **오브젝트 풀링** — `ProjectilePool` 로 총알 재사용 (`RaycastNonAlloc` 병행)
- **드래그 이동** — 마우스/터치로 화면 안에서 타워를 좌우로 이동

### 게임 플로우
- **승패 판정** — 목표 처치 수 달성 시 승리 / 머리 접촉 또는 경로 끝 도달 시 패배
- **시작 일시정지** — 시작 버튼 누르기 전까지 `Time.timeScale = 0` 으로 대기
- **빌드 종료 키** — ESC 즉시 종료 (빌드 테스트 편의)

### UI / 연출
- **월드 기준 HP 바** — 몸통 위에 부착, 카메라/스크린 동기화 (`WorldSegmentUIManager`)
- **데미지 플로팅 텍스트** — 피격 위치에 데미지 수치 표시
- **강화 선택 패널** — 몸통 N개 파괴마다 3택(공격력 / 공격 속도 / 총알 수), 최대 단계 도달 시 자동 비활성

## 구현 포인트

### 1. 거리 기반 경로 시스템 (Splines 미사용)
- `PathRoute` 가 웨이포인트 간 길이를 캐싱 → `distance → world position` 단일 변환 함수 제공
- 머리 한 점만 `headDistance += moveSpeed * Δt` 로 진행, 나머지 세그먼트는 인덱스별 뒤처짐 거리로 일괄 추종
- 세그먼트 수가 늘어도 동작 규칙 동일, 디버그·튜닝 용이
- 경로 끝 ~ 플레이어 사이 구간은 `Lerp` 로 동적 연결 → 플레이어가 좌우로 이동해도 마지막 구간이 따라옴

### 2. 몸통 파괴 시 머리 당김 메커니즘
- 단순 위치 보정이 아닌 **진행 거리 값 자체**를 보정: `headDistance -= segmentSpacing`
- 같은 프레임에 `RefreshSegmentPositions()` 호출 → 머리·잔존 몸통 모두 동일 기준으로 재계산
- 위치 보정 코드 없이 **경로 시스템 위에서 압축 연출이 자연스럽게 성립**

### 3. 적 페이즈·분노 상태 전이
- 파괴 누적 수를 트리거로 `분노(3) → 페이즈2(6) → 분노 재트리거(9)` 순 전이
- 분노 중 페이즈 전환 요청은 `pendingPhase2Transition` 플래그로 분리 → 코루틴 종료 후 안전하게 적용
- 분노 지속 시간은 `Coroutine` 으로 관리, 재트리거 시 기존 코루틴 정리 후 재시작

## 개선 과제
- `SnakeEnemy.cs` 단일 책임 분리 — 이동 / 상태 / 세그먼트 / 시각 동기 4분할 리팩토링
- 경로·스폰·강화 수치의 **ScriptableObject 데이터화** — 스테이지 추가가 코드 수정 없이 가능하도록
- 사격 판정 로직을 "상시 발사" / "가시 대상 한정" 두 모드로 토글 가능하게 개선
